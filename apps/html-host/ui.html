Publish HTML online without a host

This page is the only URL that should rank. You paste code here, hit Publish 24h, and send /p/…/. Shared pages are noindex and die after 24 hours — they are not a content silo.

Same link when you update

Publish again from the same editor session and the host overwrites that id. You do not mint a new URL for every save. That is the difference versus most “drop a file, get a new slug” tools.

HTML, CSS, and JS together

A full document can live in the HTML pane alone. If you split style.css and script.js, the host serves them as sibling files. Demo starter CSS is not attached to a pasted complete page.

FAQ

How do I share HTML online?

Paste the markup, click Publish 24h, copy the HTTPS link. Recipients open a rendered page. Opening /p/{id}/ yourself loads the editor so you can keep editing.

How is this different from GitHub Pages?

No repository, no build, no custom domain on the share link. The tradeoff is explicit: 24 hours, then the files are gone.

Can I publish only HTML?

Yes. CSS and JS panes are optional. A complete <!DOCTYPE html> document is enough.
