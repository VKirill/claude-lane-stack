# Character Limits — единая таблица

**Single source of truth для всех лимитов Google Ads 2026.** Если в другом файле что-то противоречит — этот файл primary.

## Как Google считает символы

- Считаются **Unicode code points** (не байты, не графемы).
- Русский / кириллица / эмодзи — каждый символ = 1 (для большинства случаев).
- ZWJ-эмодзи (`👨‍👩‍👧` — 5 code points) — каждый component считается отдельно. Реальное визуальное "одно лицо" может занять 5 символов лимита.
- Пробелы — считаются.
- Punctuation — считается.
- HTML-сущности (если попадут) — каждый символ.

**Принцип**: `len(string)` в Python = что Google посчитает. Это базовое предположение `validate-ads.py`.

## Шпаргалка — самые ходовые лимиты

Если не помнишь точно:
- **Headline** = **30** (RSA / PMax / Display / App / Call / Shopping is 150)
- **Description** = **90** (везде кроме Shopping 5000)
- **Long headline** = **90** (PMax / Display / Demand Gen)
- **Short description** = **60** (PMax only)
- **Business name** = **25**
- **Path** = **15** (×2 для RSA)
- **Demand Gen headline** = **40** (исключение!)
- **Video Skippable In-Stream headline** = **15** (короче, чем Search)
- **Sitelink text** = **25**
- **Callout** = **25**
- **Promotion text** = **20**

## Что Google делает при превышении

| Сценарий | Реакция Google |
|---|---|
| Headline 31 символ | Ad disapproved при создании / отмеченo как Limited при импорте |
| Description 91 символ | То же |
| Path 16 символов | То же |
| Title в Shopping >150 | Item disapproved |
| Title в Shopping 100 (но первые 70 не содержат key info) | OK по букве правила, но плохой CTR |

**НЕ полагайся на "Google обрежет красиво"** — он не обрежет, он откажет в создании ad. Всегда валидируй через `scripts/validate-ads.py` перед сдачей клиенту.

## Источник истины

Google периодически меняет лимиты (последний раз major changes 2022 для Demand Gen). Точная информация — на support.google.com/google-ads и developers.google.com/google-ads. Этот файл актуализируется при изменениях.

При сомнениях — запусти `validate-ads.py`: он использует те же лимиты что в этой таблице.
