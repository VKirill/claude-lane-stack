## Quality Score (QS) бенчмарки

QS = 1-10 шкала, складывается из:
- **Expected CTR** (35% weight) — Google прогнозирует CTR на keyword
- **Ad Relevance** (35% weight) — насколько ad matches keyword + user intent
- **Landing Page Experience** (30% weight) — LP quality, mobile, speed

| QS | Что значит | CPC modifier |
|---|---|---|
| 10/10 | Excellent — top placement, low CPC | -50% от baseline CPC |
| 8-9 | Very Good | -25% |
| 7 | Good — целевая зона | baseline |
| 5-6 | Average — okay, but room to improve | +20-30% |
| 3-4 | Poor — серьёзные проблемы | +50-100% |
| 1-2 | Critical — почти не показывается | +100-300% или нет показов |

**Целевой QS = 7+.** Все ниже — нужна оптимизация ad copy / LP / keyword targeting.

### Что улучшает QS

1. **Ad Relevance**: include exact-match keyword в headline + description
2. **Expected CTR**: writing better headlines с CTA, social proof, USP
3. **Landing Page Experience**:
   - <3 sec load time
   - Mobile responsive
   - Match ad promise (если ad обещает "30% off", LP must show "30% off")
   - Privacy policy linked
   - Easy CTA (1-2 clicks to conversion)

## Бюджет calculation — формула

```
Monthly Budget = Target Conversions × CPA
```

Reverse engineering:

```
Required Daily Clicks = Daily Budget / CPC
Required Daily Conversions = Daily Clicks × CR
Monthly Conversions = Daily Conversions × 30
```

### Example: B2B SaaS

- Industry CPC = $5
- Industry CR = 3%
- Industry CPA = $5 / 0.03 = $167 (но Industry table показывает $134 — разница из-за LP качества)
- Цель: 50 leads/month
- Бюджет: 50 × $150 = **$7500/month** или **$250/day**

### Example: E-commerce DTC

- AOV (Average Order Value) = $80
- Target ROAS = 4x → max acceptable CPA = $20
- Industry CPC = $1.5
- Industry CR = 2.8%
- Real CPA = $1.5 / 0.028 = $54 → too high for $20 cap

**Вывод**: либо снизить CPC через better QS, либо повысить CR через better LP, либо принять что текущая аудитория не работает на этот ROAS.

## Use cases — расчёт примеров

### Кейс 1: Российский B2B SaaS, target export (US)

- Industry: B2B SaaS = CPC $8, CR 2.5%, CPA $134
- Бюджет: $5000/month
- Clicks: 5000 / 8 = 625 clicks/month
- Conversions: 625 × 0.025 = ~16 leads/month
- CPA real: $5000 / 16 = $312 (выше industry median — нормально для нового аккаунта первые 2-3 месяца)
- После оптимизации (3 месяца): можем выйти на industry median $134 → 37 leads/month при том же бюджете

### Кейс 2: Российский DTC fashion, target US east coast

- Industry: E-commerce = CPC $1.5, CR 2.8%, AOV $60
- Target ROAS = 5x → max CPA = $12
- Real CPA = $1.5 / 0.028 = $54 → not viable on cold traffic
- Стратегия: Retargeting + Shopping + PMax с brand exclusion
- Retargeting CPA = ~$15-25 (achievable)
- PMax CPA при good signals = $25-40 (близко к target)

### Кейс 3: Local services (US-based, Florida pool cleaning)

- Industry: Local Services = CPC $3-5, CR 8%, CPA $40
- Бюджет: $1500/month
- Clicks: 375 / month
- Conversions: 30 leads/month
- CR call-only ads typically higher (10-15%) → лучше выбрать Call Ads format

## Что НЕ ожидать

- Первый месяц = learning phase. Не judge CPA в первые 30 дней.
- Конкурентный CPC может быть **2-3x medians** в high-competition niches (legal, finance, insurance).
- B2B Tech average sales cycle = 90+ дней. Conversion в demo, не в sale.
- Регулируемые ниши (gambling, finance, crypto) — CPC может быть $20-50.
