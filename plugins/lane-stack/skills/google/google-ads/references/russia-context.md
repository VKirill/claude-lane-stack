# Российский контекст Google Ads — критично

## Главное

**С 22 сентября 2022 года Google приостановил продажу рекламы для размещения в России.** Это бессрочно и распространяется на все форматы Google Ads.

Источник: официальное заявление Google после введения санкций / контрсанкций. Изначально это была пауза, по факту с 2022 — постоянная остановка.

## Что это значит на практике

### Заблокировано

- ❌ Создание рекламы с **таргетингом на РФ** через любые аккаунты (российские, зарубежные — Google не пускает любой Russia targeting).
- ❌ Использование **российских юр.лиц** для оплаты Google Ads — даже для зарубежного таргетинга.
- ❌ Оплата **российскими картами** (Visa / Mastercard РФ выпуска) — не проходят ни в какой Google платёжной системе.
- ❌ Все ранее активные кампании от российских клиентов приостановлены, **аккаунты заморожены**.
- ❌ AdSense выплаты в Россию не идут.

### Доступно (с оговорками)

- ✓ **Российские бренды через зарубежное юрлицо** (US LLC / EU GmbH / любая зарубежная регистрация) — могут таргетить **зарубеж**, **не РФ**.
- ✓ Реклама на русскоязычную аудиторию в **Казахстане / Беларуси / Армении / Грузии / Турции** — работает через местные или зарубежные юрлица.
- ✓ Реклама на русскоязычную диаспору в **США / Европе / Израиле** — стандартный таргетинг по языку.
- ✓ **YouTube Ads** для зарубежной аудитории (включая русскоязычную вне РФ).

### Серая зона

- ⚠ Российский VPN-таргетинг — попытка показывать рекламу российским пользователям через VPN. **Не работает**: Google определяет реальный IP/billing/account country и отказывает в показе на РФ.
- ⚠ Белорусские/казахские юрлица российских владельцев — формально работают, но Google усилил compliance-проверки. Подозрительные паттерны (резкие скачки, нетипичный таргетинг) часто приводят к suspension.
- ⚠ Реклама российского e-commerce который доставляет в РФ + использует зарубежное юрлицо — landing page может быть забанена за geo-restriction violation. Лучше для таких клиентов делать многоязычный LP с явным выбором страны.

## Альтернативы для РФ-таргетинга

| Если клиент хотел | Замена в РФ |
|---|---|
| Google Search Ads (RSA) | **Яндекс.Директ — Поиск** |
| Google Display Ads | **Я.Директ — РСЯ** (Рекламная сеть Яндекса) |
| Performance Max | **Я.Директ — Мастер кампаний** (близкий аналог) + ВК Ads |
| YouTube Video Ads | **YouTube Shorts через CPM в Я.Директе** / **VK Видео / Дзен Видео** / **TG-каналы с видео** |
| Demand Gen / Discovery | **VK Ads** (нативные посты) + **Дзен** + **TG посевы** |
| App Campaigns (UAC) | **myTarget App Campaigns** + **VK Ads** (для Android — частично через RuStore) |
| Call Ads | **Я.Директ + Calltouch** |
| Shopping Ads | **Я.Маркет реклама** / **Wildberries реклама** |

## Workflow когда клиент приходит с запросом про Google Ads

```
1. Спросить: «Какая география таргетинга»?

   Если ОТВЕТ = "Россия / СНГ только / Москва / российские пользователи"
   ─> STOP. Объяснить блокировку с 2022.
   ─> Перенаправить на yandex-direct-creatives.
   ─> НЕ продолжать с Google Ads.

   Если ОТВЕТ = "США / Европа / зарубеж / международная экспансия / экспорт"
   ─> Продолжаем с Google Ads.
   ─> Уточняем: есть ли зарубежное юрлицо для оплаты? Если нет — это блокер до его регистрации.

   Если ОТВЕТ = "Казахстан / Беларусь / Армения / Грузия / русскоязычная диаспора"
   ─> Продолжаем, но предупреждаем что Google усилил проверки для аккаунтов
      с подозрительными паттернами от российских владельцев.

   Если ОТВЕТ = "Не знаю / надо подумать"
   ─> Перенаправляем на marketing-orchestrator для стратегического разговора
      о рынках сначала, потом возвращаемся к выбору канала.

2. Уточняем оплату:
   - Зарубежная карта (от US LLC / EU юрлица) — OK
   - Российская карта / Wise (Россия) — NOT OK для Google Ads
```

## Что НЕ делать (наивные ошибки)

- ❌ «Давай попробуем — может пройдёт» — это сожжённый бюджет на setup и emotional damage клиенту.
- ❌ «Сделаем через VPN» — не работает, Google smart enough.
- ❌ «Зарегистрируем казахскую/армянскую компанию на родственника» — серьёзный compliance risk + риск account suspension.
- ❌ «Подождём — может разблокируют» — два года прошло, нет признаков отмены.

Если вам нужен трафик из РФ — есть полноценная альтернатива: Яндекс.Директ + ВК Ads + Telegram Ads. Я могу собрать стратегию под эти каналы.
>
> Если же у вас экспортный проект или таргет на зарубежные рынки — Google Ads работает, но нужно зарубежное юрлицо для оплаты и обычно зарубежный landing page. Тут я тоже помогу — давайте уточним географию и продукт.»
