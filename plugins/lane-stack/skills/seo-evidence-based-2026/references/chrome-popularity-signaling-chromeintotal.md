# Chrome Popularity Signaling (chromeInTotal)

*Book section: Глава 11.1. ПРЯМЫЕ ЗАХОДЫ И ДАННЫЕ CHROME*

## What it covers

Использование данных браузера Chrome для повышения siteAuthority через метрику chromeInTotal. Google измеряет общую популярность домена на основе прямых заходов (Direct Traffic), закладок и взаимодействий внутри браузера, минуя поиск. Эти данные формируют сигнал P* (Popularity) и влияют на NavBoost, создавая 'центр гравитации' для сущности бренда. Высокий показатель chromeInTotal действует как 'попутный ветер' для ранжирования всех страниц домена.

## Concrete steps / questions

- Создавайте брендированные точки входа вместо обычных страниц (например, /research, /academy).
- Стимулируйте пользователей добавлять важные страницы в закладки Chrome.
- Добавляйте 'возвратные якоря': обновляемые блоки, changelogs или архивы отчетов.
- Отслеживайте рост Chrome-автодополнения вашего бренда в адресной строке.
