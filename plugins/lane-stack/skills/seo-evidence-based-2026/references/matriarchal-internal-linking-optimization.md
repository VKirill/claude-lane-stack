# Matriarchal Internal Linking Optimization

*Book section: Часть 6 / Глава 4 / 4.5. Матриархальная система перелинковки*

## What it covers

Управление передачей LinkValue и LinkScore внутри кокона по строгой иерархии. Система минимизирует 'семантическое короткое замыкание', запрещая перекрестные ссылки между Support-страницами разных кластеров. Использование семантически богатых анкоров, окруженных Salient Terms, усиливает векторное расстояние (embeddings) и подтверждает тематическую чистоту веса для алгоритмов Google.

## Concrete steps / questions

- Назначение ссылок Mother (снизу вверх) для консолидации веса на Матриархе.
- Создание ссылок Daughter (сверху вниз) для индексации и навигации.
- Настройка Sister-связей (горизонтально) только внутри одного Mixed-узла.
- Ограничение Niece-ссылок (перекрестных) только уровнем Target-страниц.
- Генерация околоссылочного текста, содержащего минимум 2-3 Salient Terms цели.
