## Используй этот скилл когда

- Пишешь статью, руководство, обзор под органический трафик (Google / Яндекс)
- Оптимизируешь лендинг или страницу категории под поисковый запрос
- Нужно составить title и description страницы под CTR
- Редактируешь готовый текст — расставляешь ключи, улучшаешь структуру
- Проверяешь текст перед публикацией: плотность, заголовки, мета

- Нужна SEO-стратегия, семантическое ядро, кластеризация → seo-specialist

## Общий процесс SEO-копирайтинга

```
Запрос / бриф
    ↓
1. Анализ интента — что ищет пользователь (информация / сравнение / покупка)?
    ↓
2. Сбор ключей — основной ключ + LSI + синонимы (от специалиста или Wordstat)
    ↓
3. Структура — H1, H2, H3, FAQ, длина под тип запроса
    ↓
4. Написание текста — ключи в естественном контексте, короткие абзацы
    ↓
5. Мета-теги — title (60 зн.) + description (155-160 зн.)
    ↓
6. Внутренние ссылки — анкоры с ключами, логическая связность сайта
    ↓
7. Проверка — плотность, читабельность, дубли мета, структура
```

### Анализ поискового интента (шаг 1)

Перед написанием определи тип запроса:

| Тип | Примеры | Что делать в тексте |
|-----|---------|---------------------|
| Информационный | «как выбрать ноутбук», «что такое LSI» | Lonread, полный ответ, FAQ |
| Коммерческий / транзакционный | «купить ноутбук», «цена CRM» | Короткий лендинг, CTA, прайс |
| Навигационный | «официальный сайт Сбера» | Бренд-страница, не оптимизируем |
| Локальный | «стоматология Москва Арбат» | Гео-ключи, карта, режим работы |

## Быстрый чеклист перед публикацией

- [ ] H1 содержит основной ключ, единственный на странице
- [ ] H2/H3 покрывают LSI и сопутствующие запросы
- [ ] Плотность основного ключа 1-3% (не выше — переспам)
- [ ] LSI-слова естественно вписаны в тематическое окружение
- [ ] Title 55-60 символов, ключ в начале
- [ ] Description 155-160 символов, есть призыв к действию
- [ ] Абзацы 1-3 предложения, нет «стен текста»
- [ ] FAQ-блок (если информационный запрос) разметка готова под schema
- [ ] Нет дублей title/description на других страницах сайта
- [ ] Внутренние ссылки с релевантными анкорами

## Сигналы качества 2026 (Google + Яндекс)

**Google (данные из утечки API 2024):**
- `contentEffort` — оценивает, насколько текст «трудозатратен» с точки зрения экспертизы. Шаблонные и тонкие тексты получают низкий score.
- NavBoost влияет на позиции через поведенческие сигналы (CTR, время на странице). Мета-теги под CTR и структура текста — прямое влияние.
- Уникальность ценности: Google ищёт «оригинальный опыт» в тексте, не пересказ топ-10.

**Яндекс:**
- Контекст вокруг ключа критически важен: Яндекс лучше Google понимает тематическое окружение слова (LSI не просто вокруг ключа, а во всём тексте).
- ИКС (Индекс Качества Сайта): поведение пользователей (особенно возвраты) влияет на весь домен.
- Баден-Баден (антиспам): алгоритм снижает позиции страниц с механическим переспамом ключей.
