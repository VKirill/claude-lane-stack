# Форматы объявлений и лимиты Яндекс.Директ

> Лимиты символов считаются без пробелов в некоторых полях — всегда проверяй в интерфейсе Директа перед публикацией. Данные актуальны на 2025.

## Текстово-графическое объявление (Поиск + РСЯ)

Основной формат для поисковых и сетевых кампаний.

### Структура и лимиты

| Элемент | Лимит | Примечания |
|---------|-------|------------|
| Заголовок 1 | **35 символов** | Обязателен. Должен содержать ключевой запрос или главную выгоду |
| Заголовок 2 | **30 символов** | Необязателен на мобайле. USP, призыв, дедлайн |
| Текст объявления | **81 символ** | Основное тело. Выгода + призыв к действию |
| URL отображения | 20 символов на путь | Читаемый путь (не технический URL) |
| Целевая страница | Полный URL | Обязателен |

### Расширения (дополнения)

| Элемент | Лимит | Количество |
|---------|-------|------------|
| Уточнения | **25 символов** каждое | До 4 показывается одновременно, добавлять до 30 |
| Быстрые ссылки | **66 символов** (заголовок + описание) | 4-8 штук; минимум 4 для полного показа |
| Описание быстрых ссылок | **60 символов** | Необязательно, но улучшает CTR |
| Визитка (адрес, телефон) | По полям | Повышает доверие и занимает место |
| Цена | Число + валюта | Для объявлений с ценой в расширении |

### Правила написания заголовков

```
Пример: Заказать торт на день рождения  ← Заголовок 1 (35 символов, ключ)
        Доставка 3 часа · Без предоплаты ← Заголовок 2 (30 символов, USP)
        
Текст: Торты от 1500 ₽. Натуральный состав. Звоните — сделаем по фото!
       ← 81 символ, есть выгода и призыв
```

**Что работает:**
- Ключ в заголовке 1 = выделение жирным в поиске
- Конкретные цифры: «от 1500 ₽», «за 24 часа», «скидка 20%»
- Глаголы действия в тексте: «Закажите», «Получите», «Позвоните»
- Дедлайны и ограничения: «Только до конца месяца»

**Что не работает:**
- Заголовок «Добро пожаловать!» — нет пользы, нет ключа
- Текст без призыва: «Мы занимаемся ремонтом»
- Повторение заголовка в тексте слово в слово
- Капслок, избыточные знаки (!!!, ???) — Яндекс не пропустит модерацию

## Графические баннеры (РСЯ)

### Поддерживаемые форматы файлов
- JPG, PNG, GIF (статика)
- HTML5 (ZIP-архив с index.html)
- Максимальный вес: **150 КБ** для статики, **5 МБ** для ZIP

### Размеры баннеров

| Размер | Название | Применение |
|--------|----------|------------|
| 240×400 | Вертикальный баннер | Боковые колонки сайтов |
| 300×250 | Прямоугольник (rectangle) | Самый распространённый формат |
| 300×600 | Полустраничный | Высокая видимость, дорогой |
| 728×90 | Лидерборд | Шапка/подвал сайтов |
| 970×90 | Суперлидерборд | Широкие шапки |
| 160×600 | Небоскрёб | Боковые колонки |
| 336×280 | Большой прямоугольник | Встроен в контент |
| 320×50 | Мобильный баннер | Только мобильные устройства |
| 320×100 | Мобильный большой | Только мобильные устройства |

**Совет:** Создавай минимум 3 размера — 300×250, 728×90 и 320×50 — это покрывает большинство площадок.

### Требования к дизайну баннеров
- Текст на баннере должен читаться (минимум 12pt)
- Логотип или бренд — обязательно
- Кнопка CTA (призыв к действию) повышает CTR
- Не более 20% площади — текст (правило не жёсткое, но влияет на качество)
- Избегай мигающей анимации и агрессивных элементов

## Видеореклама

### Форматы видео

| Формат | Длина | Пропуск | Оплата | Применение |
|--------|-------|---------|--------|------------|
| In-stream пропускаемый | 15-60 сек | После 5 сек | За просмотр 30+ сек или клик | Pre-roll перед видео |
| In-stream непропускаемый | До 15 сек | Нет | За показ (CPM) | Брендовые месседжи |
| Out-stream | 15-30 сек | Автопауза при выходе | За просмотр 50% + 2 сек | В тексте страниц РСЯ |
| Бампер | 6 сек | Нет | CPM | Краткий бренд-месседж |

### Требования к видеофайлу
- Форматы: MP4, MOV, AVI, WebM
- Разрешение: минимум 640×360 (рекомендуется 1920×1080)
- Вертикальное (9:16): 1080×1920 для Яндекс Видео шортс
- Вес: до 100 МБ
- Частота кадров: 24-60 fps
- Аудио: обязательно (без звука — низкое качество пользователского опыта)

### Ключевые моменты видеокреатива
- **Первые 5 секунд решают всё** — зацепи внимание до кнопки «Пропустить»
- Бренд или продукт — показывай в первые 3 секунды
- Субтитры обязательны (30-40% смотрят без звука)
- Вертикальный формат 9:16 — снимай отдельно, не кроп из горизонтали

## Комбинаторное объявление (ResponsiveAd) — live-проверено

«Комбинаторное объявление» (ЕПК-термин) = тип `RESPONSIVE_AD` в API. Алгоритм перебирает комбинации переданных заголовков, текстов и изображений и показывает лучшие.

### Ёмкость полей

| Поле | Лимит |
|---|---|
| Заголовки (`Titles`) | до 7 |
| Тексты (`Texts`) | до 3 |
| Изображения (`AdImageHashes`) | до 5 |
| Видео | до 6 |

### Endpoint

**Использовать `/json/v501/ads`** (v501, не v5). На стандартном `/json/v5/ads` запрос с `ResponsiveAd` отклоняется с **кодом 3500** ("use v501"). Работает в классической RSYA-кампании (`TextCampaign`), не только в ЕПК.

### Форма payload

```json
{
  "AdGroupId": <id>,
  "ResponsiveAd": {
    "Titles": [{ "Text": "..." }, ...],
    "Texts":  [{ "Text": "..." }, ...],
    "Href": "https://example.com",
    "AdImageHashes": ["hash1", "hash2"]
  }
}
```

## Когда НЕ применять конкретные форматы

| Ситуация | Не используй |
|----------|-------------|
| Нет дизайнера и времени | Графические баннеры HTML5 (сложно) |
| Малый бюджет (< 5 000 ₽/мес) | Видеорекламу — мало данных для оптимизации |
| Услуги без каталога | Смарт-баннеры (нет фида) |
| Нет сайта (только WhatsApp) | Текстово-графику (нужна посадочная страница) |
| Аудитория строго B2B узкая | Широкоформатные графические баннеры РСЯ |

## Типичные ошибки с форматами

1. **Превышение лимитов** — Яндекс обрезает текст или не показывает расширения. Считай символы вручную или в Word.
2. **Один заголовок на все объявления** — теряешь возможность A/B теста. Создавай 3-5 вариантов на группу.
3. **Быстрые ссылки ведут на главную** — должны вести на конкретные страницы, иначе Яндекс снижает рейтинг.
4. **Баннеры без CTA-кнопки** — CTR падает на 15-30%.
5. **Использование одинаковых объявлений для Поиска и РСЯ** — разный контекст = разные тексты. Поиск = точный запрос, РСЯ = интерес/проблема.
6. **Не заполнены уточнения** — теряешь бесплатные символы под кликабельным объявлением.
7. **Видео без субтитров** — до 40% просмотров без звука.
