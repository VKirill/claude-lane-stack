# CSV-воркфлоу: выгрузка Key Collector → группы Яндекс Директ

## Что это за файл и откуда

Входящий файл для агента — это выгрузка из **Key Collector** в формате CSV.
Key Collector — стандартный инструмент SEO/PPC-специалиста: он собирает ключевые фразы,
снимает частотности из Wordstat, прогнозные данные из интерфейса Директа и
группирует запросы по кластерам (семантическим группам).

Типичный путь: SEO-специалист собирает семантику → кластеризует → экспортирует этот CSV →
передаёт агенту для генерации объявлений.

---

## Формат CSV — технические детали

| Параметр | Значение |
|---|---|
| Кодировка | UTF-8 **с BOM** (первые 3 байта `EF BB BF`) |
| Разделитель полей | `;` (точка с запятой, не запятая) |
| Десятичный разделитель | `,` (запятая) — например `9,52` = CTR 9.52% |
| Заголовок | первая строка, русский текст |
| Кавычки в заголовках | литеральные «» — например `Частотность «!»` |
| Строк данных | зависит от проекта; в тестовом файле 130 строк + 1 заголовок |
| Всего колонок | 25 |

**Важно:** Read tool открывает файл корректно — кодировка и кавычки отображаются как есть.
Никакого предварительного преобразования не нужно.

## Поле «Тип» — значения и что они означают

### `informational`
Пользователь ищет информацию: *как / что такое / почему / инструкция / обзор*.
Запросы типа «онлайн обучение», «что такое ЕГЭ», «как выбрать репетитора».
CTA в объявлении — обучающие материалы, бесплатный пробный урок, лидмагнит.

### `transactional`
Пользователь готов к действию: *купить / заказать / цена / стоимость / записаться*.
Запросы типа «купить курс подготовки к ЕГЭ», «стоимость занятий с репетитором».
CTA — прямая продажа, скидка, кнопка «Записаться».

### `branded`
Запрос содержит название бренда — собственного или конкурента.
Примеры: «Стобальный репетитор отзывы», «Skyeng цена», «Фоксфорд альтернатива».
Стратегия — защита бренда или конкурентная реклама.

### `navigational`
Пользователь ищет конкретный сайт или раздел: *сайт / войти / личный кабинет / скачать*.
Примеры: «стобальный репетитор войти», «100balnik сайт».
CTA — прямая ссылка на нужную страницу (лендинг, кабинет).

## Пайплайн обработки CSV для агента

Работа с файлом — pure agent task, без скриптов. Только Read tool и логика.

### Шаг 1 — Прочитать CSV через Read tool

```
Read("/path/to/file.csv")
```

Ты видишь все строки с номерами. Первая строка — заголовки, остальные — данные.

### Шаг 2 — Сгруппировать по полю «Кластер» (колонка 1)

Строки с одинаковым числом в первой колонке принадлежат одному кластеру.
Пример из тестового файла: строки со значением `1` в первой колонке — кластер «стобальный репетитор».

### Шаг 3 — Определить intent внутри кластера

Посмотри колонку «Тип» для всех строк кластера.
- Если все строки `informational` → один кластер, один intent.
- Если в кластере смешаны `informational` + `transactional` → разделить на под-группы по intent.
  Каждая под-группа получит своё объявление с соответствующим CTA.

### Шаг 4 — Сформировать группу Direct

- **Название группы** → значение «Маркерный запрос» (колонка 2).
  Если пусто — взять первое значение «Запрос» в кластере.
- **Ключевые фразы** → все значения «Запрос» (колонка 3) в кластере.
  Пропустить строки с пустым «Запросом».

### Шаг 5 — Написать объявления

Для каждой группы — минимум 2 объявления.
Используй `composition-templates.md` — выбери шаблон по intent-типу группы.
Частотность помогает расставить приоритеты: запросы с частотностью > 50 — основные,
с частотностью < 10 — дополнительные (не влияют на стратегию объявления).

### Шаг 6 — Стоп

**Не пиши Python-парсер. Не пиши bash-скрипт. Не конвертируй файл.**
Это чисто агентская задача — Read + логика + генерация текста.

**Ключевые фразы в группе (10 штук):**
- стобальный репетитор онлайн школа (частотность 190)

## Частые ошибки при работе с файлом

**BOM в первой строке** — если инструмент показывает заголовок с лишним символом в начале
(`﻿Кластер` вместо `Кластер`) — это нормально, это BOM UTF-8. Игнорировать.

**Запятая как десятичный разделитель** — значение `9,52` означает `9.52` (например, CTR 9.52%).
Для объявлений это не важно — ставки и CTR — справочная информация, не включается в текст.

**Нули в строках** — строки с нулевыми частотностями и ставками (`0;0;0;...`) реальны.
Это ключи с очень низкой частотностью. Они всё равно добавляются в группу как ключевые фразы.

**Литеральные кавычки в заголовках** — `Частотность «!»` и `Частотность «[!]»` — это
точные имена колонок. Кавычки — часть названия, не форматирование.
