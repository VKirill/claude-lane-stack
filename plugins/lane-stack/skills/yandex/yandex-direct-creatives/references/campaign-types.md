# Типы кампаний Яндекс.Директ

> Актуально для 2025-2026. Яндекс регулярно добавляет новые форматы — сверяй в справке.

## 1. Поисковые кампании (TextAds / Текстово-графические)

**Когда выбирать:**
- Пользователь уже сформулировал потребность и активно ищет решение («купить», «заказать», «цена», «отзывы»)
- Горячий спрос в нише с устойчивой поисковой активностью
- Услуги или товары с чётким семантическим ядром
- Нужна точная атрибуция: переход → заявка → продажа

**Плюсы:**
- Самый горячий трафик — человек сам нашёл тебя
- Высокая конверсия в лид по сравнению с охватными форматами
- Полный контроль над ключами и минус-словами
- Прозрачная аналитика в разрезе запросов

**Минусы:**
- Высокий CPC в конкурентных нишах (юрист, пластические операции, финансы)
- Ограниченный охват — только люди, которые ищут прямо сейчас
- Требует регулярной работы с семантикой и минус-словами
- Нет возможности «напомнить» о себе без ретаргетинга

**Лимиты и структура:**
- До 1000 групп объявлений в кампании
- До 50 объявлений в группе (рекомендуется 3-5 для A/B теста)
- До 200 ключей в группе

## 2. РСЯ (Рекламная Сеть Яндекса)

### 2а. Контекстно-зависимые объявления (текстово-графические в РСЯ)

**Когда выбирать:**
- Охват аудитории на этапе формирования спроса
- Ретаргетинг — «догнать» тех, кто был на сайте но не конвертировался
- Ниша с отложенным решением (квартиры, авто, дорогие услуги)
- Дополнение к поисковым кампаниям для полного покрытия воронки

**Плюсы:**
- Значительно дешевле поиска по CPC
- Огромный охват: 65 000+ сайтов-партнёров Яндекса
- Возможность таргетинга по интересам, поведению, look-alike
- Форматы автоматически адаптируются под площадку

**Минусы:**
- Трафик холоднее — человек не искал прямо сейчас
- CTR ниже (0.3-1% против 5-15% на поиске)
- Сложнее контролировать качество площадок
- Требует отдельного подхода к текстам и визуалу

### 2б. Графические баннеры в РСЯ

**Когда выбирать:**
- Брендинг и узнаваемость
- Есть дизайн-ресурс для создания баннеров
- Акции, сезонные кампании с ярким визуальным предложением

**Форматы:** см. [ad-formats.md](ad-formats.md)

## 3. Мастер кампаний (МК)

**Когда выбирать:**
- Клиент-новичок или нет ресурса на ручную настройку
- Малый бизнес с ограниченным бюджетом (от 10 000 ₽/мес)
- Нужно быстро запустить кампанию без глубокого погружения
- Услуги с понятным сайтом, который Яндекс может «прочитать»

**Плюсы:**
- Автоматически создаёт объявления на основе сайта
- Объединяет Поиск + РСЯ в одном инструменте
- Минимум настроек — запуск за 15 минут
- Алгоритм Яндекса оптимизирует под заявки автоматически

**Минусы:**
- Меньше контроля: нельзя точно управлять ключами
- Непрозрачная оптимизация — сложно понять, что работает
- Не подходит для сложных ниш с жёсткими требованиями к аудитории
- Качество автоматических текстов часто ниже ручных

**Когда НЕ применять:**
- Медицинские клиники, юридические услуги (строгая модерация + ниша требует точных текстов)
- e-comm с большим каталогом — лучше смарт-баннеры или динамика
- Когда важна детальная аналитика по ключевым словам

## 4. Смарт-баннеры (Smart Banners)

**Когда выбирать:**
- Интернет-магазин с товарным фидом (XML/YML)
- Ретаргетинг: показывать именно те товары, которые смотрел пользователь
- Категорийный ретаргет: «смотрел смартфоны — покажи все смартфоны»

**Плюсы:**
- Персонализация без ручной работы — баннер генерируется из фида
- Динамически подставляют цену, название, картинку товара
- Высокая релевантность = хороший CR у «тёплой» аудитории
- Автоматическое обновление при изменении фида

**Минусы:**
- Нужен качественный и актуальный товарный фид
- Не подходит для услуг без чёткого каталога
- Ограниченный контроль над внешним видом баннера
- Требует настройки электронной коммерции в Метрике

**Когда НЕ применять:**
- Услуги (нет фида) — используй обычную РСЯ
- Маленький каталог (менее 50 товаров) — ручная РСЯ эффективнее

## 5. Динамические объявления

**Когда выбирать:**
- Большой товарный каталог (тысячи SKU), где ручное написание нереально
- Агрегаторы, маркетплейсы, порталы с разделами
- Необходимо охватить длиннохвостые запросы автоматически

**Плюсы:**
- Масштаб: одна настройка = сотни тысяч объявлений
- Яндекс сам генерирует заголовки из содержимого страниц
- Хорошо работают в нишах с большой семантикой (запчасти, одежда, электроника)

**Минусы:**
- Меньше контроля над текстами объявлений
- Нужна хорошо структурированная страница / фид
- Ошибки в каталоге = ошибки в объявлениях

**Когда НЕ применять:**
- Услуги или небольшой сайт — тексты лучше писать вручную
- Страницы с тонким контентом (парсер Яндекса создаст некачественные заголовки)

## 6. Видеореклама

**Когда выбирать:**
- Брендинг и охват (верх воронки)
- Продукт требует демонстрации (гаджеты, beauty, недвижимость)
- Есть готовый видеоролик или ресурс на производство
- Целевая аудитория активно потребляет видео (Яндекс Видео, КиноПоиск)

**Форматы:**
- **In-stream (pre-roll)**: показывается до/во время видео; 5 сек — пропускаемый, 15-30 сек — непропускаемый
- **Out-stream**: встроен в контент страниц РСЯ; 15-30 сек; оплата за просмотр
- **Вертикальное видео (9:16)**: для шортс-форматов в Яндекс Видео и мобильных размещений

**Плюсы:**
- Высокая вовлечённость и запоминаемость бренда
- Дешёвый охват по CPM в сравнении с ТВ
- Возможность таргетинга по аудитории Яндекса

**Минусы:**
- Высокая стоимость производства качественного ролика
- Низкий прямой конверсионный эффект
- Требует отдельных KPI (просмотры, охват, VTR)

**Когда НЕ применять:**
- Малый бюджет — видео требует минимум 30 000-50 000 ₽/мес для значимой статистики
- Прямая конверсионная задача (лиды, заявки) — используй Поиск + РСЯ

## Decision matrix: задача → тип кампании

| Задача | Тип | Примечание |
|--------|-----|------------|
| Горячий спрос, прямые заявки | Поиск (TextAds) | Основная рабочая лошадка |
| Охват новой аудитории дёшево | РСЯ текстово-графическая | Отдельная кампания от Поиска |
| «Догнать» посетителей сайта | РСЯ ретаргетинг | Сегмент в Метрике |
| Быстрый запуск, новичок | Мастер кампаний | С оговорками про контроль |
| e-comm, ретаргет по товарам | Смарт-баннеры | Нужен фид |
| Большой каталог, длиннохвост | Динамические объявления | Нужен сайт/фид |
| Брендинг, охват, видео | Видеореклама | Верх воронки |

---

## Типичные ошибки при выборе типа кампании

1. **Мешать Поиск и РСЯ в одной кампании** — разные аудитории, разная логика ставок и текстов. Всегда разделяй.
2. **Запускать МК вместо ручных кампаний «потому что проще»** — теряешь контроль и прозрачность.
3. **Смарт-баннеры для услуг** — нет фида = нет результата.
4. **Видеорекламу с маленьким бюджетом** — статистика не накопится, оптимизация невозможна.
5. **Динамику на «пустой» сайт** — Яндекс-парсер создаст нерелевантные заголовки.
6. **Игнорировать Единую Перфоманс Кампанию (ЕПК)** — в 2024-2026 Яндекс активно переводит на неё: стоит тестировать параллельно с классикой.
