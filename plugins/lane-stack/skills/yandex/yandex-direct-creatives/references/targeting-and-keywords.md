# Таргетинг и ключевые слова Яндекс.Директ

> Актуально для 2025-2026. Алгоритмы матчинга и автостратегии Яндекса обновляются — сверяй нюансы в справке.

## Ключевые слова: типы соответствия

Яндекс.Директ по умолчанию использует широкое соответствие с элементами «умного» матчинга. Операторы позволяют уточнять, насколько жёстко слово должно совпадать с запросом.

### Операторы соответствия

| Оператор | Синтаксис | Что делает | Пример |
|----------|-----------|------------|--------|
| Широкое (по умолчанию) | `заказать торт` | Синонимы, словоформы, перестановки | «заказ тортов», «купить торт» |
| Плюс (обязательное слово) | `+заказать торт` | Слово должно быть в запросе | Не покажет «купить торт», покажет «заказать торт Москва» |
| Восклицательный знак (точная форма) | `!заказать !торт` | Фиксирует форму слова | Не покажет «заказ тортов» |
| Кавычки (фразовое соответствие) | `"заказать торт"` | Только эта фраза (+ слова до/после) | «заказать торт недорого», но не «торт заказать» |
| Квадратные скобки (порядок слов) | `[заказать торт]` | Фиксирует порядок слов в фразе | Не покажет «торт заказать» |
| Минус-слово | `-бесплатно` | Исключает запросы с этим словом | Убирает нецелевую аудиторию |

### Стратегия подбора ключей

```
Горячие ключи (высокий CPC, высокий CR):
  «купить», «заказать», «цена», «стоимость», «Москва»
  → приоритет для поисковых кампаний

Тёплые ключи (средний CPC, средний CR):
  «лучший», «рейтинг», «отзывы», «сравнение»
  → хороши для информационного контента + ретаргетинг

Холодные ключи (низкий CPC, низкий CR):
  «что такое», «как выбрать», «виды»
  → только для РСЯ или брендинга
```

**Правило чистоты группы:** один смысловой кластер = одна группа объявлений. Не смешивай «купить диван» и «диван цена» в одну группу — разные интенты требуют разных текстов.

## Минус-слова

### Уровни добавления

| Уровень | Где добавляется | Охват |
|---------|-----------------|-------|
| Кампания | Настройки кампании → «Минус-фразы» | Блокирует для всех групп кампании |
| Группа объявлений | Настройки группы → «Минус-фразы» | Блокирует только для конкретной группы |
| Ключевое слово | Оператор «-» в самой фразе | Ультра-точный контроль |

### Стратегии создания списка минус-слов

**Базовый список (добавлять всегда):**
```
бесплатно, своими руками, сделать самому, DIY, скачать, 
смотреть онлайн, торрент, реферат, курсовая, 
вакансия, работа, резюме, обучение, курсы
```

**Алгоритм сбора минус-слов:**
1. Запустить кампанию с небольшим бюджетом (тест)
2. Через 3-7 дней открыть отчёт по поисковым запросам
3. Найти нецелевые запросы — добавить как минус-слова
4. Повторять раз в 1-2 недели в первый месяц

**Минус-слова по типичным нишам:**

Услуги B2C:
```
-бесплатно, -своими руками, -самостоятельно, -форум, -отзыв (осторожно), -видео
```

e-comm / товары:
```
-б/у, -бу, -секонд, -авито, -оптом (если нет опта), -дешевле, -дропшиппинг
```

B2B услуги:
```
-студент, -реферат, -курсовая, -для чайников, -что такое
```

## Аудиторный таргетинг

### Look-alike (похожие аудитории)

**Что это:** Яндекс находит пользователей, похожих по поведению на вашу исходную аудиторию (посетители сайта, список клиентов, конвертированные).

**Как настроить:**
1. Создать сегмент в Яндекс.Аудиториях (минимум 1 000 пользователей)
2. На основе сегмента создать look-alike
3. Добавить аудиторию в условие показа РСЯ или настроить корректировку

**Уровни сходства:** 1 (очень похожие, маленький охват) → 5 (широко похожие, большой охват). Начинай с уровня 3-4.

### Ретаргетинг (RLSA-аналог)

**Сегменты для ретаргетинга:**
- Все посетители сайта за 30/60/90 дней
- Посетители конкретных страниц (карточка товара, корзина)
- Пользователи, пробывшие на сайте более N секунд (вовлечённые)
- Конвертировавшиеся (для up-sell / cross-sell)
- «Бросившие корзину» — горячий сегмент для e-comm

**Настройка:** Яндекс.Метрика → Сегменты → Аудитории Директа → Условие подбора.

### Сегменты Яндекс.Метрики

Директ напрямую интегрируется с Метрикой. Можно использовать:
- Цели (достигли определённого действия)
- Сегменты по поведению (источник, устройство, регион)
- Аудиторные сегменты (пол, возраст — если счётчик накопил данные)

## Геотаргетинг

### Ручной vs регионы

| Вариант | Когда | Как |
|---------|-------|-----|
| По регионам (список городов) | Работаешь в конкретных городах | Настройки кампании → «Регион показа» |
| Расширенный гео (+ область вокруг) | Клиенты едут из области | Опция «Расширенный географический таргетинг» |
| Исключение регионов | Не работаешь в отдельных городах | Минус-регионы |

### Корректировки по гео

Можно повышать или понижать ставки для отдельных регионов:
- Москва/СПб: часто +20-50% (дороже, но выше средний чек)
- Регионы: -20-30% (ниже покупательская способность)

**Совет:** не выставляй корректировки до накопления статистики (минимум 2-4 недели).

## Расписание показов

### Стандартное расписание

По умолчанию: 24/7. Менять только если есть чёткие данные о конверсиях по времени.

**Когда ограничивать расписание:**
- Есть колл-центр только в рабочее время (заявки ночью = потеря лида)
- Нишевые пики: «доставка еды» — вечер рабочих дней
- Плановый бюджет маленький: сосредоточить на самых конверсионных часах

**Как настроить:**
1. Посмотреть отчёт Метрики: «Аудитория → Время суток»
2. Найти часы с высоким CR и низким CPA
3. Ограничить нерентабельные периоды через корректировки -100%

### Корректировки ставок по времени

Можно повышать ставки в пиковые часы:
```
Пн-Пт 9:00-18:00 — основное рабочее время (+10-20%)
Пт вечер + Вс — часто провал по B2B (-30-50%)
```

## Корректировки ставок

### Виды корректировок

| Тип | Диапазон | Применение |
|-----|----------|------------|
| Устройства | -100% до +1200% | Снизить мобайл, если конвертит хуже |
| Пол | -100% до +1200% | Продукты с чёткой гендерной аудиторией |
| Возраст | -100% до +1200% | Молодёжные или возрастные продукты |
| Аудитория (look-alike / ретаргет) | -100% до +1200% | Поднять ставки для тёплой аудитории |
| Регион | -90% до +900% | Приоритет в прибыльных городах |
| Время | -100% до +200% | Пиковые часы |

**Важно:** корректировки перемножаются. Если +50% по Москве и +20% по мобайлу — итого +80%, а не +70%.

### Корректировки по устройствам (особый случай)

Мобайл часто конвертирует хуже на сложных услугах (B2B, дорогие товары). Сначала смотри данные в Метрике, только потом ставь -30-50% на мобайл. Для доставки еды, такси, срочных услуг — мобайл может быть приоритетом.

## Когда НЕ применять аудиторный таргетинг

| Ситуация | Почему |
|----------|--------|
| Аудитория < 1 000 пользователей | Look-alike не создаст (минимальный порог) |
| Нет счётчика Метрики на сайте | Нет данных для сегментов и ретаргетинга |
| Только запускаешь (0 данных) | Ретаргетинг добавь через 2-4 недели, когда накопится аудитория |
| Узкая B2B ниша с жёсткими ограничениями | Look-alike «разбавит» аудиторию нерелевантными |

## Типичные ошибки с таргетингом

1. **Широкие ключи без минус-слов** — бюджет уходит на нерелевантные запросы. Минус-слова — обязательный этап запуска.
2. **Смешивать горячие и холодные ключи в одной группе** — разная конверсия, разные тексты нужны.
3. **Ретаргетинг на всех посетителей сайта** — включая отказников (провели < 5 сек). Фильтруй: «провели > 30 сек» или «просмотрели 2+ страницы».
4. **Корректировки без данных** — применять «на глаз» до накопления статистики = деньги на ветер.
5. **Расширенный геотаргетинг без контроля** — можно получить показы из регионов, куда не доставляешь.
6. **Забыть про кросс-минусовку** — если группы пересекаются по ключам, они конкурируют друг с другом на аукционе.
7. **Использовать только широкое соответствие** — без операторов «+» и «!» бюджет сливается на нецелевые запросы.
