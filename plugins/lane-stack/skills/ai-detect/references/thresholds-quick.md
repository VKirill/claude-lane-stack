## 2. Базовые категории — что видно без NLP-инструментов

| Показатель | Человек | AI-флаг |
|---|---|---|
| CV длины предложений | >0,5 (то 5 слов, то 25) | <0,3 |
| CV длины абзацев | >0,5 | <0,3 |
| Морфология: время глаголов | смесь: прошедшее в кейсах, будущее в прогнозах | доминирует настоящее (>80 %) |
| Морфология: лицо | «вы», «мы», 1-е лицо в кейсах | доминирует 3-е лицо, местоимений <3 % |
| Морфология: наклонение | императив в инструкциях, сослагательное в сценариях | почти только изъявительное |
| Named Entities | разные типы: имена (PERSON), законы/приказы (LAW), деньги (MONEY), названия методик и работ | шаблонно: только организации + даты |
| Эмоциональный профиль | пики в кейсах и оценках (диапазон валентности >0,4) | всё сглажено, нейтрально |
| Лексическая плотность (ADJ+NOUN+VERB+ADV) | >55 % | <50 % |
| Сжимаемость | повторяющиеся формулировки = текст хорошо сжимается = AI-флаг | формулировки не дублируются |

## 3. Принципы коррекции (Режим 3 методики — обязательны для writer)

1. **Персона, а не правила.** У текста должен быть автор с позицией. Правки «по метрикам»
   без персоны дают новый вид роботности — «отредактированный AI-текст».
2. **Тире-коннекторы и искусственные хеджи-вставки — сами AI-маркеры.**
   Никогда не использовать их как приём «гуманизации».
3. **Разговорность и жаргон ≠ человечность.** Механическая вставка «ну», «вот», «типа»
   создаёт новый искусственный паттерн. Частицы — только где персона реально бы их сказала.
4. **Работать только с TOP-3 вкладчиками в роботность.** Не трогать то, что в норме.
5. **Читабельность важнее низкого процента.** Лучше 25–30 % с сохранённым стилем,
   чем 10 % ценой разрушения текста.
6. **Конкретика вместо общих мест:** «Когда клиент получает ответ за 5 минут вместо
   2 часов, он возвращается» — а не «повышение качества обслуживания важно».
7. **Хеджи по Храповицкому («возможно», «примерно», «около») запрещены как вставки.**
   Реальную неопределённость выражай условием: «если вуз работает по ФГОС 2023 года — срок другой».

## 4. Целевые бюджеты для статьи ~1300–1800 слов (сводка для самопроверки)

- H2/H3: ≤1 на 300 слов, суммарно 6–8; FAQ-вопросы — полужирным, не заголовками.
- Тире «—»: ≤8 на 1000 слов, ≤1 на абзац; «термин — определение» ≤2 на статью.
- Tricolon (ровно 3 элемента): ≤1 на статью.
- Дискурсивные частицы: 2–4 на 500 слов (6–10 на статью), только уместные.
- Когезивные мосты: ≤2 на 500 слов.
- «Например» и синонимы: ≤3 на 500 слов, без цепочек.
- Интенсификаторы: ≤2 на 500 слов.
- Дигрессии (скобки, «кстати»): 1–4 на статью.
- Абзацы не с тезиса (пример/вопрос/деталь/цифра): ≥25 %.
- Прошедшее/будущее время: ≥15 % глаголов; «вы» — минимум в трети разделов.
- Точный маркерный запрос: ≤2 в теле (плюс title/H1).
- Каждый факт развёрнут в одном месте (+1 повтор в таблице или сниппете).
- Финал — не резюме.
