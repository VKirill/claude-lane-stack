# Craft floor (lane)

From impeccable `craft-floor.md`. Brief / `DESIGN.md` can earn an exception.
Reaching for these when the axis is free is a fail.

## Verify

- Contrast: body ≥4.5:1, large ≥3:1. No gray text on a colored surface.
- Depth: shadow has offset + blur. Zero-offset glow is decoration.
- Spacing: tight groups, generous separation, more space above a heading than below.
- Type: 65–75ch body, display max ~6rem, tracking ≥ `-0.04em`.
- Motion: one authored moment. Ease-out from an already-visible default.
- States: hover, disabled, loading, error, empty, keyboard focus.
- Browser chrome: selection, caret, scrollbar, focus ring, underline-offset, tabular nums — theme them.
- Copy: control names the action; error names the problem and the fix. (Texts: `copy-lead`.)

## Refuse (unless DESIGN.md pinned it)

- Same-size icon+heading+text cards as the page structure. Nested cards.
- Hero-metric template (big number + small label + accent stats).
- Eyebrow/kicker above every heading. Ban — do not earn it back.
- Section numbers 01/02/03 unless sequence is the content.
- Modal for a task that needs no interruption.
- Gradient text. Glass/blur as default decoration.
- Colored side stripe >1px on cards/alerts.
- Hard 4px offset shadow outside a neobrutalist world.
- Inter / system display face as the voice of a branded marketing page when `DESIGN.md` named another face. On operate UI, keep the product face.
- Emoji/Unicode as the icon system.
- Bounce/elastic easing.
