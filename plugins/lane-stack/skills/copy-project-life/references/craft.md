## Audience

- Customer = hero. Brand = guide. They buy the **internal** problem.
- Villain = root cause, not a competitor logo.
- `if_we_vanished` = what they do today (status quo).
- Feature → so what → theme. Max 4 themes.
- Persona = story of the day they started looking + five rings. Empty ring = `unknown`.
- Grunt test: offer / life better / how to buy — if any blank, page is not ready.

## Page

| Awareness | First screen |
|---|---|
| 5 Most | Offer + price + CTA |
| 4 Product | Proof + difference |
| 3 Solution | Us vs alternatives |
| 2 Problem | Name the wound, then the way |
| 1 Unaware | Story / mechanism; no hard sell |

Never put a level-5 H1 on a level-2 reader.

4 U’s (score 1–4): Urgency · Uniqueness · Specificity · Usefulness. Ship if ≥3 axes ≥3.
Types: how-to, news, number, reason-why, proof, command. Pick one.

Flow: Attention → Need → Satisfy → Prove → Ask.
First sentence short. Risk-reversal only if the offer allows it.
CTA = verb + object they want. One primary. No “Learn more”.

## Disk order

Board: `.agents/copy/INDEX.md`. Update it when a file’s `status` changes.

`unknown` → `draft` → `fillable` → `approved` → `locked`  
`locked` = do not rewrite. `on_site: yes|no` on pages only (live HTML ≠ copy status).

Research lands in `research/inbox/YYYY-MM-DD-<slug>.md`. After a lift → `used/`. Noise → `dead/`. Never append to one `web.md`.
