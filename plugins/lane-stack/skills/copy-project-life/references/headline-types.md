# Headline types (Caples / Bly)

Prefer one type. Mix only if the 4 U’s still hold.

- **How-to** — how they get the result
- **News** — what just changed
- **Question** — only if the answer is the offer
- **Command** — verb they want to do
- **Testimonial / proof** — named result
- **Specific number** — “7 mistakes”, not “many”
- **Reason-why** — because + mechanism

4 U’s (Bly): Urgency · Uniqueness · Ultra-specificity · Usefulness. Score 1–4. Keep if ≥3 axes ≥3.

Sources: Caples *Tested Advertising Methods*; Bly *The Copywriter’s Handbook*.
