# Schwartz awareness (page must pick one)

| Level | Reader already… | First screen |
|---|---|---|
| 5 Most aware | Knows us, wants the deal | Offer + price + CTA |
| 4 Product aware | Knows the product, not sure it's for them | Proof + difference |
| 3 Solution aware | Knows the category, not us | Why this vs alternatives |
| 2 Problem aware | Feels the pain, no named fix | Name the wound, then the way |
| 1 Unaware | Not looking | Story / mechanism; no hard sell |

Never write a level-5 H1 on a level-2 visitor.
Source: Eugene Schwartz, *Breakthrough Advertising* (method, not a reprint).
