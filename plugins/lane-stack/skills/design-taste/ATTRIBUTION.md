## Adopted

- Context first: infer page kind, audience, job, references, brand evidence, and constraints before judging a surface.
- A contextual three-dial reading for variance, motion, and density.
- Evidence based redesign review covering type, color, layout/rhythm, assets, interaction states, accessibility, and purposeful motion.
- Practical preflight and explicit degraded evidence when screenshots, tokens, or assets are missing.
- Scope for landing pages, portfolios, and redesigns, with cabinets, admin screens, and data tables kept out of landing-page guidance.

## Deliberately omitted or adapted

- React, Next.js, Tailwind, Motion, GSAP, package installation, and code skeletons: this lane reviews the existing project stack and never writes product UI.
- Arbitrary numeric copy, hero, grid, or asset quotas; new font prescriptions; palette hex lists; and blanket font or aesthetic bans. Inter remains valid when the project or brand uses it.
- Mandatory image-generation or external-image sourcing, because asset choice belongs to the project's evidence and the owning writer.
- Upstream content and implementation advice that belongs to `project-design`, `page-prototype`, `impeccable-ui`, `copy-lead`, or a UI run.

No upstream source text or code is copied verbatim into the adapter. If substantial upstream material is added later, retain the notice below with that material.
