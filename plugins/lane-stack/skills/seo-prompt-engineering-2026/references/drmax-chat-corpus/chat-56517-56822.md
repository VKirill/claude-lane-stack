ЗАДАЧА:

Для КАЖДОГО анкорового варианта:

1. Проанализируй:
   – степень точного совпадения с:
     • H1 акцептора,
     • основным Primary Keyword,
     • URL slug акцептора;
   – коммерциализацию формулировки;
   – повторяемость сущности без контекста;
   – вероятность шаблонности (SEO-footprint).

2. Определи Over-Optimization Score по шкале:
   0–20   → Минимальный риск  
   21–40  → Низкий риск  
   41–60  → Умеренный риск  
   61–80  → Повышенный риск  
   81–100 → Критический риск  

3. Укажи:
   – тип риска:
     • Exact-match abuse
     • Partial-match saturation
     • Brand overuse
     • Commercial bias
     • Semantic narrowness
   – краткое объяснение (1–2 предложения).
