## Сообщение администраторского канала 45612 — 2025-04-14T21:50:25

**Контекст сообщения 45607, на которое дан ответ:**

> так я ж об этом и говорил в первый раз. Вдруг она у тебя есть, а не хватает фраз 3,4,8.... а первая фраза встречается только один раз, а нужно 3

блин, хотел расписать - но получится мега портянка. Тут на самом деле достаточно долго объяснять суть. Попробую кратко.
1. Есть текст - для него есть несколько ключей - для каждого ключа мы рассчитываем благодаря семантике (на основе контента конкурентов) какими фразами (n-грамамми) данный ключ становится важным в контентее конкурента. Таким образом все эти фразы (n-граммы) нам становятся доступны только после всех расчетов.
2. Количество прямых вхождений ключа в текст мы наблюдаем через TFIDF. Важно не переспамливать ключом ( а для молоого сайта, так сделать число вхождений ниже чем у конкурентов, ибо если им сойдет с рук переспам, то новому сайту - нет).
3. Добираем семантическую близость через синонимы и близкие термины, те что мы получили  после оценки контента конкурентов
4. Встраиваем аккуратно и естественно оные n-граммы, не спамим. Количественной оценки тут нет и быть не может. Я юзаю чат бот, где прошу естественно встроить такие то ключи в текст (список прилагаю), не меняя суть текста. 
5. Полученный контент засовываем в окошко текстовое и вновь сравниваем с конкурентами. Если по семантике не добрали релевантности (как у конкурентов) - идем к пункту 4.
6. Если по TFIDF перебрали (для каждого ключа) - то убираем прямое вхождение.

Тут смысл не только в том, чтобы набить ключами контент, а в том чтобы правильно их встроить. Имеет значение расположение ключей в тексте, в контексте предложений и прочее.
