## Сообщение администраторского канала 7362 — 2023-06-21T18:53:40

**Контекст сообщения 7360, на которое дан ответ:**

> Спасибо. Я еще раз перечитаю статью и напишу вопросы если не дойдёт )

По простому 
1. Тематический кластер - он же кокон по французски имеет несколько уровней страниц
2. Каждая родительская страница имеет несколько дочерних
3. Каждая ветка сгрупирована вокруг одного понятия (сущности)
4. Ключевые слова каждой подстраницы (нижележащей страницы) являются подзапросами текущей страницы ( например текущая страница имеет ключ "кирпич", тогда 3 подстраницы описывают ключи: "силикатный кирпич", "облицовочный кирпич", "огнеупорный кирпич".   А, например для страницы "огнепорный кирпич" подстраницы создаем по ключам "углеродистый огнеупорн. кирпич", "кварцевый огнеупорный кирпич" и "шамотный огнеупорный кирпич". В свою очередь для каждой из этих подстраниц создаем новые под-под страниц. Например для "шамотный огнеупорн. кирпич" делаем подстраницы "Особо плотные шамотные огнеупорные кирпичи", "Повышеннопористые  шамотные огнеупорные кирпичи" и т.д.)
5. Сверху вниз, каждый родитель ссылается на свои подстраницы
6. Снизу вверх, каждая подстраница ссылается на родителя и на тот уровенб, который будем двигать. Например страница Повышеннопористые  шамотные огнеупорные кирпичи" будет ссылаться на "шамотные огнеупорные кирпичи" (по умолчанию на уровень вверх) и на "кирпичи", потому как мы хотим задвинут ключ "кирпич" в ТОП1
7. Страницы самого нижнего уровня будут иметь крайне малый вес, поэтому организовываем их перелинковку на 1 уровне (например 2-3 ссылки на страницы того же уровня нашего дерева, но не чужого (например мы не ссылаемся на дерево "Окна")
8. Используем правильные анкоры, не спамим, разбавляем при перелинковке вверх

Вот минимально описан тематический кластер. Остальное читайте на сайте
