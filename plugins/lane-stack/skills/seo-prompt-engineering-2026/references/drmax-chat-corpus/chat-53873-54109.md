3. Использование REST API вместо admin-ajax.php
Если ваши плагины используют admin-ajax.php, это загружает ВСЮ WordPress на каждый запрос.

Проблема: admin-ajax.php загружает:

wp-load.php

wp-config.php

wp-settings.php (все плагины, темы)

/wp-admin/admin.php

Решение: Используйте REST API (в 2-5 раз быстрее):

javascript
// Плохо: admin-ajax.php
fetch('/wp-admin/admin-ajax.php', {
    method: 'POST',
    body: new FormData({action: 'my_action'})
});

// Хорошо: REST API
fetch('/wp-json/myapp/v1/endpoint', {
    method: 'GET'
});
