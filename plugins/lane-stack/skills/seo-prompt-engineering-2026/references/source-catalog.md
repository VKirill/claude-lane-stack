# Каталог и статус источников

## Правило первоисточника

Оригинальные промпты лежат только в [originals/](originals/INDEX.md). Они скопированы
побайтово и проверяются по `MANIFEST.tsv` и `SHA256SUMS`. Исправления, перевод,
сокращение, объединение версий и «улучшение» текста оригинала запрещены. Любая памятка
вне `originals/` — производная навигация, а не замена промпта.

## Иерархия доверия

1. Оригинальное вложение официального канала «Промпты от DrMax».
2. Оригинальный GIST Content Logic Skill v3.3.
3. Оригинальный prompt pack книги v1.5.
4. Текст книги или официального канала DrMax.
5. Сообщение от имени администраторского канала в DrMax SEO Chat с сохранённым
   контекстом ответа.
6. Сообщения остальных участников чата — только контекст вопроса; они не включены как
   самостоятельные советы.

Новая версия официального промпта имеет приоритет над старой для новых задач. Старые
версии сохранены для истории и воспроизводимости.

## Корпуса

| Корпус | Что внутри | Как читать |
|---|---|---|
| [originals/](originals/INDEX.md) | Неизменённые `.txt` и `.md` | Открывать выбранный промпт целиком |
| [drmax-prompt-channel-corpus/](drmax-prompt-channel-corpus/INDEX.md) | Описания и инструкции официального prompt-канала | Сначала `CATALOG.md`, затем нужный пост |
| [drmax-channel-corpus/](drmax-channel-corpus/INDEX.md) | Официальный SEO-канал | Искать узкую тему, не загружать целиком |
| [drmax-chat-corpus/](drmax-chat-corpus/INDEX.md) | Ответы админ-канала и контекст вопросов | Использовать как практическое уточнение, не как абсолютный канон |
| [books/](books/INDEX.md) | Три PDF, заново преобразованные в Markdown | Читать нужную главу по указателю |

## Состав книг

- `GIST в примерах` — практическая активация, Creation/Audit mode, быстрые проверки,
  мета-поля, пакетная работа и типичные сбои.
- `Промптоведение для SEO-стратегов v1.5` — проектирование промптов и последовательность
  из 25 исследовательских систем с полными и lite-версиями.
- `Доказательное SEO` — ранжирование, техническое SEO, семантика, доверие,
  стратегия, аудит и проектирование LLM-процессов.

## Ограничения преобразования

- Книги извлечены непосредственно из исходных PDF через `pdftotext -layout`; номера
  исходных страниц сохранены комментариями `source-page`.
- Удалены повторяющиеся колонтитулы и отдельные номера страниц. Текст не пересказывался.
- Медиа из Telegram не копируются. Каждый исключённый нетекстовый пост записан в
  `OMITTED-MEDIA.md` соответствующего корпуса. Содержание картинки нельзя считать
  изученным без отдельного OCR-аудита.
- В чате ID `channel1682731429` обозначает администраторский канал. Это не доказывает,
  что каждое сообщение лично написал Максим Храповицкий.

## Поиск

```bash
rg -n -i "интент|кластер|serp" references/drmax-*-corpus references/books
rg -n -i "название системы" references/drmax-prompt-channel-corpus/CATALOG.md
```

После нахождения системы переходите к её файлу в `references/originals/`, а не копируйте
текст из производного архива.
