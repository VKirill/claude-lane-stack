Твоя задача — провести не поверхностный обзор рынка, а построить карту конкурентного поля для проекта, чтобы на ее основе можно было принимать стратегические SEO-решения, выбирать правильных конкурентов для глубокого разбора и не тратить ресурсы на ложные ориентиры.

Тебе нужен результат уровня decision-grade:
не список известных компаний,

кто реально конкурирует с проектом в поиске,
по каким кластерам и интентам это происходит,
какие типы игроков давят на выдачу,
какие типы страниц у них работают,
какие конкуренты важны стратегически,
какие конкуренты выглядят опасными только внешне,

--------------------------------------------------
ЧТО ИМЕННО СЧИТАТЬ КОНКУРЕНТОМ
--------------------------------------------------

Ты обязан разделять следующие типы игроков:

1. SEO-конкуренты
Игроки, которые реально конкурируют с проектом в органической выдаче по темам, кластерам, интентам и типам страниц.

2. Прямые бизнес-конкуренты
Игроки, продающие похожий продукт или услугу той же аудитории, даже если они не всегда сильны в SEO.

3. Косвенные конкуренты
Игроки, которые решают ту же задачу другим способом или забирают схожий спрос через смежное предложение.

4. Контентные конкуренты
Игроки, которые конкурируют за информационные или исследовательские интенты, даже если не являются прямыми бизнес-конкурентами.

5. Агрегаторы и маркетплейсы
Игроки, которые доминируют в выдаче за счет структуры, ассортимента, охвата или бренда.

6. Медиа и обзорные площадки
Игроки, которые перехватывают верхнюю и среднюю часть воронки, особенно в информационных и сравнительных интентах.

7. UGC-площадки и сообщества
Форумы, Reddit-подобные площадки, Q&A-ресурсы, каталоги отзывов, сообщества, которые конкурируют за выдачу и пользовательское доверие.

8. Локальные каталоги, справочники, карты
Особенно важно для локальных ниш и геозависимого спроса.

Не смешивай эти типы игроков.
Твоя задача — не просто собрать их в один список, а разложить по ролям и по степени угрозы.

--------------------------------------------------
ТРЕБОВАНИЯ К СБОРУ ИНФОРМАЦИИ В ИНТЕРНЕТЕ
--------------------------------------------------

Работай как аккуратный исследователь, а не как генератор правдоподобных догадок.

Обязательные правила:

1. Не опирайся на одно наблюдение, если оно влияет на стратегический вывод.
- Проверяй ключевые выводы по нескольким независимым сигналам.
- Если подтверждений мало, помечай вывод как гипотезу.

2. Сначала собирай фактические сигналы, потом интерпретируй.
Фактические сигналы включают:
- какие домены и страницы повторяются в выдаче;
- по каким темам и интентам они пересекаются с проектом;
- какие типы страниц они используют;
- какие разделы и хабы у них существуют;
- какие форматы контента встречаются повторно;
- какие trust-сигналы видны;
- какие коммерческие блоки и поверхности заметны;
- как часто игрок появляется в релевантных зонах выдачи.

3. Анализируй не домен “в целом”, а по слоям:
- по кластерам;
- по интентам;
- по типам страниц;
- по этапам воронки;
- по форматам;
- по сегментам аудитории;
- по гео;
- по зонам коммерческой ценности;
- по trust-layer;
- по SERP-роли.

4. Не делай вывод о конкуренте по главной странице.
Изучай:
- основные разделы;
- шаблоны страниц;
- категории;
- сравнительные страницы;
- информационные страницы;
- коммерческие страницы;
- страницы use case / industry / audience / geo, если они есть;
- навигационную логику;
- внутреннюю связанность разделов.

5. Не путай наличие страницы с качественным покрытием.
Проверяй:
- насколько тема раскрыта глубоко;
- соответствует ли страница интенту;
- есть ли у конкурента системный охват, а не единичная публикация;
- есть ли связка между информационным и коммерческим слоем;
- видны ли признаки регулярной стратегии, а не случайного накопления контента.

6. Отдельно фиксируй:
- сильные бренды, которые мало пересекаются с проектом в SEO;
- сильные SEO-игроки, которые не являются прямыми бизнес-конкурентами;
- агрегаторы и медиа, которые мешают росту по части выдачи;
- игроков, которые опасны только в одном типе интента или одном page type.

7. Если информация неполная, прямо указывай:
- чего не хватает;
- что требует дополнительной проверки;
- какие выводы нельзя считать надежными.

2. Построй карту уровней конкуренции
Разложи конкуренцию по уровням:
- конкурент по ядру предложения;

- конкурент по отдельным кластерам;
- конкурент по информационным интентам;
- конкурент по коммерческим и сравнительным интентам;
- конкурент по локальным интентам;
- конкурент по поддерживающим или постпокупочным интентам.

3. Определи реальных SEO-конкурентов
Найди тех игроков, которые системно пересекаются с проектом в поиске.
Оцени:
- частоту пересечения;
- ширину пересечения;
- глубину пересечения;
- качество пересечения;
- опасность пересечения для роста проекта.

4. Разложи игроков по типам
Для каждого обнаруженного игрока определи:
- тип игрока;
- роль в SERP;
- по каким интентам он силен;
- по каким кластерам он присутствует;
- в каких форматах и типах страниц он чаще всего выигрывает.

5. Раздели конкуренцию по интентам
Отдельно анализируй:
- информационные интенты;
- определительные и объяснительные интенты;
- problem-solving интенты;
- investigational интенты;
- сравнительные интенты;
- коммерческие интенты;
- транзакционные интенты;
- локальные интенты;
- implementation / support / troubleshooting интенты;
- trust-validation интенты;
- смешанные интенты.

6. Раздели конкуренцию по типам страниц
Покажи, какие игроки сильны в следующих типах страниц:
- category pages;
- service pages;
- product pages;
- local pages;
- glossary / definition pages;
- long-form guides;
- comparison pages;
- alternatives pages;
- use case pages;
- industry pages;

- methodology pages;
- FAQ hubs;
- support / troubleshooting pages;
- case studies;

- listings / directory pages;

- review pages / best pages.

7. Раздели конкуренцию по этапам воронки
Отдельно покажи, кто перехватывает спрос на этапах:
- раннее осознание;
- исследование проблемы;
- изучение решений;
- сравнение вариантов;
- оценка доверия;
- коммерческое рассмотрение;
- решение;
- локальный выбор;
- внедрение;
- поддержка;
- удержание / повторный спрос.

8. Отдели реальную силу от видимой силы
Для каждого важного игрока оцени:
- где у него реальное стратегическое преимущество;
- где его сила держится на бренде;
- где его сила держится на масштабе сайта;
- где его сила держится на формате SERP;
- где он действительно хорошо закрывает интент;
- где создается только видимость сильного присутствия.

9. Выяви ложных конкурентов
Обязательно покажи:
- кого часто считают конкурентом по инерции;
- кто кажется важным брендом, но слабо пересекается в реальном SEO;
- кто силен только в очень узком участке спроса;
- кто не должен попадать в основной shortlist для следующего этапа.

ОСОБЫЕ МОДИФИКАТОРЫ
--------------------------------------------------

Адаптируй анализ под тип проекта.

Если проект — SaaS:
- уделяй больше внимания страницам use case, industry, integrations, alternatives, pricing, onboarding, support.

Если проект — e-commerce:
- уделяй больше внимания category pages, фильтрам, атрибутным страницам, сравнению брендов, marketplace-давлению, отзывам и карточкам.

Если проект — B2B:
- уделяй больше внимания ролевой сегментации, proof-элементам, долгому циклу выбора, отраслевым страницам, ROI-интентам и внедрению.

Если проект — local business:
- уделяй больше внимания картам, локальным каталогам, страницам городов, отзывам, локальному trust-layer и сервисным модификаторам.

Если проект — affiliate / review:
- уделяй больше внимания comparison pages, methodology pages, review trust, AI-компрессии кликов и медиа-конкуренции.

Если проект — media / publisher:
- уделяй больше внимания тематическому охвату, кластеризации, SERP-компрессии, AI-answerability и конкуренции с UGC и крупными издателями.

Если проект относится к YMYL или trust-sensitive тематике:
- отдельно оцени роль экспертизы, проверяемости, прозрачности, автора, reviewer-слоя, регуляторных рисков и барьеров доверия.

--------------------------------------------------
ОЦЕНКА УВЕРЕННОСТИ
--------------------------------------------------

Для каждого важного вывода указывай уровень уверенности:

Высокая уверенность:
- вывод подтверждается несколькими наблюдениями и не противоречит общей картине.

Средняя уверенность:
- вывод правдоподобен, но часть сигналов ограничена или неполна.

Низкая уверенность:
- вывод основан на фрагментарных сигналах, требует проверки и не должен быть основой сильного решения без подтверждения.

ЧЕГО НЕЛЬЗЯ ДЕЛАТЬ
--------------------------------------------------

- Не выдавай список известных брендов вместо карты конкуренции.

- Не заканчивай работу простым списком доменов.

3. Типология игроков
Сделай структурированную карту типов игроков:
