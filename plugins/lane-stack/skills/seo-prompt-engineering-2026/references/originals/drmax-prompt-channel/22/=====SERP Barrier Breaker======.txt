## ЭТАП 1 — ОЦЕНКА КАЧЕСТВА КОНТЕНТА (фильтр)

Перед анализом барьеров ответь честно на три вопроса:

1. **Оригинальность**: содержит ли материал инсайты, данные или точку зрения, которую нельзя получить из первых трёх результатов Google по этой теме?
   - Оценка: [0–10] + обоснование

2. **Форматное соответствие**: соответствует ли формат материала тому, что Google показывает для этих запросов (списки / нарратив / таблицы / инструмент / FAQ)?
   - Оценка: [0–10] + обоснование

3. **Дифференциация**: есть ли в материале что-то, чего НЕТ в топ-5 результатах?
   - Оценка: [0–10] + обоснование

**ВЕРДИКТ:**
- Если все три оценки ≥ 7 → «Качество достаточное, проблема в позиционировании» → переходи к Этапу 2
- Если хотя бы одна < 7 → «Первоочередная задача — исправить качество» → укажи конкретно что именно

## ЭТАП 2 — ДИАГНОСТИКА 7 БАРЬЕРОВ

Оцени каждый барьер по шкале: 🔴 Критический / 🟡 Значимый / 🟢 Не проблема

### БАРЬЕР 1: Технические ограничения
- Проверь (на основе доступных данных): индексирование, рендеринг JS, canonical-теги, наличие noindex, внутренние ссылки на страницу
- Если URL предоставлен: проверь через анализ HTML-структуры
- Сигналы риска: <head> с noindex, отсутствие внутренних ссылок в тексте, contont в JS-компонентах
- **Оценка:** [🔴 / 🟡 / 🟢] + конкретная находка + рекомендация

### БАРЬЕР 2: Intent Mismatch (несоответствие намерению)
- Определи намерение запроса: [informational / commercial / transactional / navigational]
- Определи доминирующий формат выдачи для этих запросов: [списки / руководства / инструменты / сравнения / UGC]
- Сравни с форматом предоставленного материала
- Учитывай SERP-фичи: AI Overview покрывает ли этот тип запросов? Reddit/UGC присутствует?
- **Оценка:** [🔴 / 🟡 / 🟢] + конкретный gap + рекомендация

### БАРЬЕР 3: Authority Gap (разрыв авторитета)
- Оцени по сигналам в тексте: есть ли ссылки на внешние авторитетные источники? Есть ли данные, исследования, источники?
- Определи вероятный диапазон DR конкурентов для указанных запросов (высококонкурентные vs. нишевые ниши)
- Есть ли признаки того, что сайт — новый или нишевый домен без накопленного доверия?
- **Оценка:** [🔴 / 🟡 / 🟢] + рекомендация по репозиционированию (weight class matching)

### БАРЬЕР 4: Topical Depth Gap (глубина темы)
- Охватывает ли материал тему изолированно или является частью контентного кластера?
- Перечисли смежные подтемы, которые ОТСУТСТВУЮТ в материале, но необходимы для топикального авторитета
- Выяви, есть ли «семантические дыры»: понятия, связанные сущности, FAQ-вопросы, которые ожидает Google для данной темы
- **Оценка:** [🔴 / 🟡 / 🟢] + карта пропущенных подтем + рекомендация

### БАРЬЕР 5: Engagement Loop (петля вовлечённости)
- Есть ли в материале элементы, которые удерживают пользователя и снижают bounce: примеры, кейсы, инструкции, данные, визуал?
- Оцени «satisfaction potential»: уйдёт ли пользователь с ответом или вернётся в поиск?
- Признаки слабого engagement loop: нет примеров, только абстрактные советы, нет конкретики, нет CTA
- **Оценка:** [🔴 / 🟡 / 🟢] + конкретные недостающие элементы + рекомендация

### БАРЬЕР 6: Content Differentiation (уникальный угол)
- Что делает этот материал ОТЛИЧНЫМ от того, что уже есть в топ-5?
- Определи: есть ли собственные данные, первичный опыт, авторская методология, нестандартная структура?
- Используй тест: «Мог ли это написать кто угодно с GPT и первыми 5 результатами Google?»
- **Оценка:** [🔴 / 🟡 / 🟢] + конкретный дифференцирующий потенциал + рекомендация

### БАРЬЕР 7: Brand / Entity Recognition (узнаваемость бренда)
- Упоминается ли автор / бренд? Есть ли атрибуция экспертизы?
- Есть ли сигналы entity-связи: упоминания в релевантных источниках, авторская страница, связь с Knowledge Graph?
- Есть ли брендовый поисковый спрос (подразумевается из контекста)?
- **Оценка:** [🔴 / 🟡 / 🟢] + рекомендации по entity-building

## ЭТАП 3 — СТРАТЕГИЯ ДОСТИЖЕНИЯ ТОПА

На основе диагностики разработай приоритизированный план действий.

### 3.1 Приоритизация барьеров
Составь матрицу: [Барьер] × [Критичность] × [Сложность исправления] × [Временной горизонт результата]

| Барьер | Критичность | Сложность | Горизонт | Действие |
|--------|-------------|-----------|----------|----------|
| ... | ... | ... | ... | ... |

### 3.2 Стратегия репозиционирования
- Если выявлен Authority Gap: предложи конкретные **альтернативные ключевые запросы** с меньшей конкуренцией и соответствующим weight class
- Если выявлен Topical Gap: опиши минимальный **кластерный план** (3–5 поддерживающих страниц)
- Если выявлен Intent Mismatch: предложи **реструктуризацию формата** (что убрать, что добавить, как изменить структуру H1–H3)

### 3.3 Конкретные изменения в контенте
Предоставь список изменений в формате:
- **УДАЛИТЬ:** [конкретный элемент] — причина
- **ДОБАВИТЬ:** [конкретный элемент] — причина + где именно разместить
- **ПЕРЕФОРМАТИРОВАТЬ:** [что] → [во что] — причина
- **УСИЛИТЬ:** [слабый раздел] → [конкретно чем]

### 3.4 AI-видимость (AI Overviews / AI Mode)
Оцени потенциал попадания в AI-ответы:
- Есть ли в материале «цитируемые блоки» (чёткое утверждение + обоснование в 2–3 предложениях)?
- Есть ли конкретные факты, цифры, определения — то, что AI цитирует охотнее всего?
- Рекомендации по созданию passage-level citability

### 3.5 Дорожная карта (недели → результат)
- **Неделя 1–2:** [срочные технические / структурные исправления]
- **Неделя 3–6:** [контентные улучшения и кластерная работа]
- **Месяц 2–3:** [authority building, entity recognition, distribution]
- **Ожидаемый результат:** [конкретный прогноз по позициям / AI-видимости]
