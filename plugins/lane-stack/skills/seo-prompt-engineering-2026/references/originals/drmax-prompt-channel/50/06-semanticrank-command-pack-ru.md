# SemanticRank Orchestrator — ready-to-use command pack (RU)

## Назначение

Этот файл — набор готовых команд для запуска системы SemanticRank Orchestrator в чате. Его задача — избавить пользователя от ручной сборки инструкций каждый раз, когда нужно проверить HTML на семантическую верстку, определить тип страницы, найти semantic gaps и получить практические рекомендации.

Команды ниже рассчитаны на работу вместе с файлами:

- `01-semantic-html-general-skill.md`
- `02-semantic-html-page-types.md`
- `03-super-prompt-semantic-html-audit.md`
- `04-html-semantic-audit-report-template.md`
- `05-semanticrank-orchestrator-ru.md`

---

## Как использовать этот файл

1. Подключить все 5 базовых файлов системы.
2. При необходимости подключить этот 6-й файл как библиотеку готовых команд.
3. Вставить HTML, URL или HTML-фрагмент.
4. Выбрать подходящую команду ниже.
5. При необходимости адаптировать одну-две строки под свою задачу.

## Блок 1. Универсальные команды

### Команда 1. Универсальный запуск полного аудита

```text
Используй SemanticRank Orchestrator.
Режим: Full audit.
Задача: определить тип страницы по HTML, проверить качество семантической верстки, найти semantic gaps, упущенные возможности для улучшения ранжирования, LLM-extractability и AI-citation readiness.
Фокус: нативные HTML-теги, practical SEO value, внедряемые рекомендации по существующему контенту.
```

### Команда 2. Универсальный production-отчет

```text
Используй SemanticRank Orchestrator.
Режим: Production report.
Задача: выполнить стандартизированный аудит HTML-страницы по строгому шаблону output.
Определи тип страницы, найди semantic gaps, сильные стороны разметки и выдай backlog-ready рекомендации.
```

### Команда 3. Быстрая проверка HTML-фрагмента

```text
Используй SemanticRank Orchestrator.
Режим: Quick audit.
Проверь этот HTML-фрагмент на качество семантической верстки.
Определи, что уже сделано правильно, что критично сломано и какие 5 правок дадут максимальный эффект.
```

### Команда 4. Сравнительный аудит нескольких страниц

```text
Используй SemanticRank Orchestrator.
Режим: Comparative audit.
Проанализируй несколько HTML-страниц, определи тип каждой страницы, выдели повторяющиеся template-level semantic gaps и отдельно покажи page-level проблемы.
В конце дай общие рекомендации по шаблону.
```

## Рекомендуемая схема выбора команды

Если задача пользователя такая:

- быстро посмотреть фрагмент — брать Quick audit;
- сделать серьезный разбор одной страницы — брать Full audit;
- получить стандартизированный документ — брать Production report;
- сравнить несколько шаблонов или страниц — брать Comparative audit;
- получить только задачи в разработку — брать команду про backlog-ready output;
- проверить конкретную подсистему страницы — брать узкоспециализированные команды.
