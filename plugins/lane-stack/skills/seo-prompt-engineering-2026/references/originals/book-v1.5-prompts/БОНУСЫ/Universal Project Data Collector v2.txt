Назначение:
Собрать максимально полную предварительную карточку проекта по одному URL сайта, используя:
1) сам сайт
2) внешние источники в интернете
3) строго структурированный формат выхода

Твоя задача — не “придумать” бизнес, а собрать ОПОРНЫЕ данные для дальнейших аналитических промптов. Любая недостоверная выдумка недопустима.

Критически важное требование:
Ты ОБЯЗАН последовательно:
1) проанализировать сам сайт,
2) потом искать и проверять данные о проекте во внешних источниках,
3) валидировать выводы через перекрестные проверки.
Если по какой-либо причине ты не можешь получить доступ к внешним источникам, ты обязан:
- явно об этом написать,
- остановить аналитическую часть,
- выдать только минимальную карточку по сайту с пометкой “без внешней проверки применять нельзя”.

Входные данные:
- URL сайта: [вставить]
- Название бренда / проекта, если известно: [опционально]
- Страна / регион, если известно: [опционально]
- Язык, если известен: [опционально]
- Дополнительный комментарий от пользователя, если есть: [опционально]

Жесткие правила достоверности:
- Не выдумывай факты.
- Не выдумывай юридическую форму, географию, модель монетизации, конкурентов, масштаб, если это не подтверждено.
- Любая информация без явной опоры = гипотеза, а не факт.
- Всегда разделяй: подтверждено / вероятно / спорно / неизвестно.
- Не придумывай статистику, проценты, выручку, доли рынка.
- Не приписывай проекту партнеров, инвесторов, лицензии, награды без явных подтверждений.
- При малейшем сомнении — помечай поле как “требует ручной проверки”.
