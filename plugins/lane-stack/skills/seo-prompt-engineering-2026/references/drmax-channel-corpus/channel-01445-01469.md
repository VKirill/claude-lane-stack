➡️Разделяйте сущность, выбор и действие по разным документам. Одна страница объясняет, что это такое. Вторая - как выбрать. Третья - как внедрить. Четвертая - почему не сработало. Это уже не раздувание кластера, а управляемое снятие внутренней избыточности.

➡️Смотрите не только на SERP, но и на собственный сайт. Если ваши страницы можно переставить местами (а то и безболезненно удалить) без потери смысла, у вас не архитектура, а дублирующийся массив текста.

☄️ FAQ Rich Results - конец эпохи

7 мая 2026 года Google разместил официальное уведомление[ на странице FAQPage](https://developers.google.com/search/docs/appearance/structured-data/faqpage?hl=en) в документации Search Central: "FAQ rich results are no longer appearing in Google Search". Сигналы первыми зафиксировали Search Engine Land (Barry Schwartz) - живые обсуждения подтвердили мгновенное исчезновение сниппетов.

Полный таймлайн удаления таков:

➡️Август 2023 - FAQ убраны для всех сайтов, кроме gov и health

➡️7 мая 2026 - FAQ-сниппеты исчезли из SERP для всех, включая gov/health

➡️Июнь 2026 - Удаление FAQ appearance filter, rich result report и поддержки в Rich Results Test

➡️Август 2026 - Удаление поддержки FAQ rich result из Search Console API

Что делать с FAQPage-разметкой: оставить или удалить?

Здесь мнения разделились, и важно понять нюанс.

➡️Аргумент за удаление: фича, ради которой разметка ставилась, мертва. GSC-отчёт по ней тоже исчезает. С точки зрения "ROI от разметки" - нулевой для SERP.

➡️Аргумент за сохранение: Google явно написал в документации, что продолжает использовать FAQPage structured data для понимания содержимого страницы, даже без визуального результата. Исследования AEO (Answer Engine Optimization) фиксируют более высокий процент цитирования страниц с чистой structured data в AI Overviews и LLM-ответах. Удалить схему сейчас - снизить AI-цитируемость без какого-либо плюса.

Вывод: разметку не трогать. Убрать нужно только ожидание, что она влияет на CTR в SERP.

Почему это произошло

Официального объяснения от Google нет, но паттерн очевиден:

➡️Google освобождает SERP-пространство для AI Overviews - expandable FAQ-дропдауны конкурировали с AI-сниппетами визуально и семантически

➡️FAQ-разметка массово злоупотреблялась для захвата лишней SERP-выдачи без пользы для пользователя

➡️Форматы "вопрос-ответ" Google теперь обрабатывает через AI Overviews напрямую, без необходимости показывать их отдельным rich result блоком

Что проверить прямо сейчас

➡️GSC → Enhancements → FAQ - открыть отчёт, пока он ещё доступен (до июня), скачать список URL с FAQPage-разметкой. Это база для следующих шагов.

➡️Сравнить CTR до и после 7 мая - в GSC → Performance → Compare: взять диапазон 1–6 мая vs 7–11 мая для страниц с FAQ-разметкой. Резкое падение CTR при сохранении позиций = потеря FAQ-сниппета как CTA.

➡️Решить по каждой странице - если страница жила только за счёт FAQ-сниппета, нужен новый CTR-драйвер: переписать мета-тайтл/дескрипшн, добавить How-To schema (где применимо), тестировать видеотранскрипт-разметку.

Разметку не удалять - но переориентировать FAQ-секции под AEO-логику: answer-first структура (прямой ответ 40–80 слов в начале блока) повышает шансы попасть в AI Overviews.

🎮 Микроразметка и ИИ-цитирования

На днях [Ahrefs выкатил результаты](https://ahrefs.com/blog/schema-ai-citations/) двухэтапного исследования. Сначала - корреляционный анализ шести миллионов страниц, затем контролируемый эксперимент с 1885 страницами, которые добавили JSON-LD разметку между августом 2025 и мартом 2026.

Корреляция вводит в заблуждение. Страницы, которые цитирует ИИ, втрое чаще содержат JSON-LD, чем не цитируемые. Эту цифру часто преподносят как "доказательство" пользы разметки - но это ложная зависимость. Сайты с разметкой просто в среднем лучше: выше авторитет, сильнее контент, больше ссылок.

Четыре независимых статистических теста дали одинаковый результат: добавление разметки не увеличивает ИИ-цитирования на страницах, которые ИИ уже видит.

Важное ограничение исследования: В выборку попали только страницы, которые уже находились в "поле зрения" ИИ - имели 100 и более цитирований до эксперимента. Для страниц, которые ИИ ещё не замечает, вопрос остаётся открытым.

Отдельный эксперимент компании searchVIU показал: пять крупных ИИ-систем (ChatGPT, Claude, Perplexity, Gemini, Google AI Mode) при прямом обращении к странице полностью игнорируют JSON-LD - они читают только видимый HTML. Это означает: при реальном поисковом запросе разметка не работает напрямую. Её роль при индексировании и обучении моделей по-прежнему не изучена.

Разметку НЕ нужно использовать для этих целей:

➡️Ради роста ИИ-цитирований на страницах, которые уже видны - данные опровергают этот сценарий

➡️Как замена качественному содержанию - корреляция "разметка = авторитет" объясняется качеством сайта, а не кодом

➡️FAQ-разметка ради расширенных сниппетов в поиске - с 7 мая 2026 года Google перестал их показывать


Разметку НУЖНО использовать по этим причинам:

➡️Расширенные результаты в выдаче - типы "Товар", "Рецепт", "Мероприятие", "Инструкция", "Навигационная цепочка" продолжают работать и дают визуальное преимущество в выдаче

➡️Граф знаний и распознавание сущностей - Google строит граф сущностей; разметка ускоряет привязку бренда, автора, организации к нужной сущности

➡️Голосовой поиск - структурированные данные остаются основным сигналом для голосового ответа

➡️Страницы вне поля зрения ИИ - для страниц, которые ИИ ещё не индексировал, разметка потенциально помогает попасть в круг рассмотрения; данных нет, но логика обоснована

Разметка через JavaScript и разметка в HTML - ИИ-сканеры обрабатывают их по-разному; разметка, встроенная через JavaScript, игнорируется при прямом обращении, но иначе учитывается при индексировании

Привожу некоторые дополнительные трюки с разметкой:

1. Speakable - почти никто не применяет

Тип Speakable указывает ИИ и голосовым помощникам, какой именно фрагмент страницы является каноническим ответом на вопрос. Это прямой способ сказать Google: "вот тот абзац, который нужно процитировать". Охват применения ничтожен - конкуренция за эту разметку близка к нулю. Официально функция доступна для новостных изданий на английском, португальском, немецком и французском языках; для остальных сайтов разметка не даёт гарантированного результата, но не запрещена и может влиять на выбор фрагмента в ИИ-ответах.

Пример реализации: отметить заголовок и первые один-два абзаца статьи как "голосовой фрагмент" - по аналогии с тем, как оптимизируют выделенный сниппет в текстовом поиске, только для аудио.


2. VideoObject + транскрипт - двойной сигнал

Тип VideoObject с полем transcript даёт ИИ-системам машиночитаемый текст видеоролика без необходимости его распознавать. Механика: страница с материалом по теме + встроенное видео + VideoObject с транскриптом = три независимых сигнала об одной теме вместо одного. Ahrefs прямо называет это отдельной гипотезой для проверки.
