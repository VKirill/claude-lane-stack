# MVP and story concepts

- **Story** — who, what, why, in the user's words; one story = one or more pieces with one promise each.
- **MVP** — the smallest set of stories that lets a real user do the job end to end; everything else is deferred in CONTEXT.md.
- **Walking skeleton** — the first phase wires every layer with the thinnest piece so later phases only add.
- **Vertical slice** — a piece cuts through UI, logic and data for one behaviour, not one layer for many.
