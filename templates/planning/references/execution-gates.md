# Execution step gates

A piece of a wave moves only through these gates, each decided by code:

1. **Contract lint** — owns_paths, checks, promise, read_first exist.
2. **Base green** — the checks the piece names pass on main before the writer starts (or the red is recorded as pre-existing).
3. **Writer done** — the writer's report has APPROACH and LESSON lines.
4. **Ownership** — only owned files changed.
5. **Checks** — every check exits 0 in the sandbox.
6. **Plan → fact** — the promise and the forecast hold.
7. **Critic** — advisory unless critic.challenge_high and the piece is high risk.
8. **Owner word** — only with owner.words on.
9. **Merge** — lands on main; the post-merge check runs on main.
