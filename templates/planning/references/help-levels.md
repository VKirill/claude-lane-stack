# Four help levels

When a worker is stuck, help escalates one level at a time:

1. **Hint** — the stall check names the pattern (same error three times) and suggests a different angle.
2. **Context** — the PM adds the missing file, rule or memory note to the contract and sends again.
3. **Specialist** — a helper of another role (debugger, design-lead, researcher) works the question and reports.
4. **Owner** — only with owner.words on, or a question only the owner can answer (a business decision, a secret he holds).
