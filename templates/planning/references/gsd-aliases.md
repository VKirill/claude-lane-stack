# Transitional /gsd-* aliases

SMA kept the /gsd-* command names of its predecessor (GSD) as aliases. Lane Stack installs them only with
`./install.sh --gsd-aliases`: each alias skill points at the Lane Stack skill of the same job.

| alias | Lane Stack |
|-------|-----------|
| /gsd-plan-phase | lane-plan + Lane Pilot phase driver |
| /gsd-execute-phase | Lane Pilot phase (execution) |
| /gsd-verify-work | Lane Pilot run-goal |
| /gsd-progress | lane-plan roadmap analyze |
| /gsd-debug | lane-plan debug new |
