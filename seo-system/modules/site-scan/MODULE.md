# Module: site-scan

## Purpose
Deterministic HTML fetch + structure extract, versioned so history remains.

## Protocol
- Full: `seo-scan <slug> --url … --max-pages N`
- Page: `seo-scan <slug> --page URL`
- After deploy: `seo-scan <slug> --rescan` or specific pages

## Then
Agent deep-reads analysis.md → GIST Audit / technical-seo / content-quality modules.
